#  Sales Performance Dashboard 

##  Project Overview

The Sales Performance Dashboard is a data analytics and business intelligence project developed using Microsoft Power BI.

The project focuses on analysing sales performance across different regions, sales channels, product categories, customer types, and sales representatives.

The dashboard provides an interactive way to explore sales data, monitor revenue performance, identify important business trends, and gain insights into sales operations.

The goal is to transform raw sales data into meaningful visual insights that can support business monitoring and decision-making.

##  Project Objectives

- Analyse overall sales and revenue performance.
- Monitor sales performance across different geographical regions.
- Compare the performance of different sales channels.
- Evaluate revenue generated by individual product categories.
- Understand purchasing patterns of new and returning customers.
- Analyse individual salesperson performance.
- Identify monthly sales trends.
- Present business insights through interactive Power BI visualisations.

##  Tools and Technologies

- **Microsoft Power BI:** Data visualisation, dashboard development, and business intelligence.
- **Microsoft Excel:** Dataset storage and source data management.
- **Data Analytics:** Sales performance analysis and business reporting.

##  Dataset Description

The project uses a sales dataset containing **2,000 records and 12 columns**.

The dataset covers sales transactions from January 1, 2026, to December 31, 2026.

### Dataset Columns

| Column | Description |
|---|---|
| Order ID | Unique sales transaction identifier. |
| Date | Date of the transaction. |
| Region | Geographical sales region. |
| Sales Channel | Channel through which the sale was made. |
| Customer Type | Identifies new and returning customers. |
| Product Category | Category of the purchased product. |
| Product | Name of the product sold. |
| Salesperson | Sales representative responsible for the transaction. |
| Quantity | Number of units sold. |
| Unit Price | Price per unit. |
| Discount | Discount applied to the transaction. |
| Revenue | Revenue generated from the transaction. |

##  Key Insights

Based on the analysis of the supplied dataset, the following observations were identified:

### 1. Overall Sales Performance

- Total Revenue: **3,462,605.32**
- Total Orders: **2,000**
- Total Units Sold: **7,552**
- Average Revenue per Order: **1,731.30**

### 2. Regional Performance

The Central region generated the highest revenue, followed closely by the North region.

| Region | Revenue |
|---|---:|
| Central | 802,603.64 |
| North | 787,107.33 |
| East | 658,276.02 |
| South | 627,690.52 |
| West | 586,927.81 |

### 3. Sales Channel Performance

Online sales generated the highest revenue among the four sales channels.

| Sales Channel | Revenue |
|---|---:|
| Online | 1,112,657.22 |
| Corporate Sales | 1,013,948.69 |
| Retail Store | 906,981.87 |
| Marketplace | 429,017.54 |

### 4. Product Category Performance

Computers contributed the largest share of total revenue.

| Product Category | Revenue |
|---|---:|
| Computers | 2,058,536.24 |
| Monitors | 737,406.12 |
| Networking | 291,619.52 |
| Storage | 269,998.05 |
| Accessories | 85,917.49 |
| Office Supplies | 19,127.90 |

### 5. Customer Analysis

Returning customers generated more revenue than new customers.

| Customer Type | Revenue |
|---|---:|
| Returning | 2,368,353.98 |
| New | 1,094,251.34 |

This highlights the significant contribution of returning customers to overall business revenue.

### 6. Salesperson Performance

Mei Tan recorded the highest revenue among the sales representatives, generating **319,585.32** in sales.

### 7. Monthly Sales Trends

June recorded the highest monthly revenue, generating **373,916.30**.

February recorded the lowest monthly revenue, generating **219,186.72**.

These variations provide an opportunity to investigate monthly sales performance and identify potential seasonal patterns.

##  Business Value

The dashboard provides insights that can help businesses:

- Identify high-performing product categories.
- Understand regional sales performance.
- Evaluate the effectiveness of different sales channels.
- Monitor individual salesperson contributions.
- Understand customer purchasing patterns.
- Track monthly revenue fluctuations.
- Identify areas that may require improved sales strategies.

##  How to Use the Project

1. Clone or download this repository.
2. Ensure Microsoft Power BI Desktop is installed.
3. Open `sales_performance_dashboard.pbix` using Power BI Desktop.
4. Explore the different dashboard pages.
5. Interact with the available visualisations and report filters.

##  Project Conclusion

This project demonstrates the application of business intelligence and data visualisation techniques to sales performance analysis.

By organising sales information into an interactive Power BI dashboard, the project makes it easier to understand business performance across multiple dimensions.

The analysis highlights the importance of monitoring revenue, regional contributions, product performance, customer behaviour, and monthly sales trends.

Overall, the project demonstrates how data analytics and visualisation can transform raw transactional data into actionable business insights.
